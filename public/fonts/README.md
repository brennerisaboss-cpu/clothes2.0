# Sprat

The display face used for page heads. Free, but not served from a CDN, so it is
not fetched automatically.

Download it from https://www.freefaces.gallery/typefaces/sprat, convert the
regular weight to woff2, and drop it here as `Sprat-Regular.woff2`. Every page
head picks it up on the next load.

Until then Bodoni Moda stands in — the didone Sprat descends from, so the page
reads the same at a glance.
